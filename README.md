# gh-docs-mcp

gh-docs-mcp provides a private, read-only Model Context Protocol endpoint. Phase 1 adds the native bare Git store, repository catalog, and confined reader for synthetic SHA-1 and SHA-256 repositories. The MCP endpoint serves the Phase 0 fixture.

See the [storage and reader contract](docs/storage.md), [qualification procedure](docs/deployment-prerequisites.md), [architecture decisions](docs/decisions), and [observed results](docs/implementation-status.md).
