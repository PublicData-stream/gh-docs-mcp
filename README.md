# gh-docs-mcp

gh-docs-mcp provides a private, read-only Model Context Protocol endpoint. The native Git store and confined reader support SHA-1 and SHA-256. Sync verifies private candidates from operator-approved sources and supports atomic publication, rollback, and guarded maintenance. The MCP endpoint serves the Phase 0 fixture.

See the [storage and reader contract](docs/storage.md), [synchronization runbook](docs/synchronization.md), [publication and recovery](docs/publication.md), [qualification procedure](docs/deployment-prerequisites.md), [architecture decisions](docs/decisions), and [observed results](docs/implementation-status.md).
